01 / About
ziqodevs is a place for ideas that are too interesting to leave as ideas.

We are an independent developer group focused on making things from scratch. Our work can range from tiny utilities and web projects to games, developer tools, experimental software and programming languages.

$ ziqo init
idea → build something weird
code → make it work
test → probably break it
repeat → indefinitely
